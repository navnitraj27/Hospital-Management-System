# 🏥 Hospital Management System (Java)

A modular console-based Hospital Management System developed using core
Java and Object-Oriented Programming principles.\
This system simulates real-world hospital operations including patient
management, doctor records, admissions, authentication, and secure data
handling.

------------------------------------------------------------------------

## 📌 Project Overview

The Hospital Management System is designed to efficiently manage
hospital operations using a structured and modular architecture.\
It supports managing patients, doctors, admissions, ambulance services,
and hospital capacity while maintaining persistent data using local file
storage.

This project demonstrates practical implementation of OOP concepts and
real-world system design using Java.

------------------------------------------------------------------------

## 🚀 Features

-   Add and manage patient records
-   Manage doctor details
-   Process hospital admissions
-   Track ambulance availability
-   Monitor hospital capacity
-   Basic user authentication system
-   Data encryption utility
-   File-based data persistence
-   Structured modular architecture

## ▶️ How to Run the Project

1.  Clone the repository:

    git clone
    https://github.com/navnitraj27/Hospital-Management-System.git

2.  Navigate to the project folder:

    cd Hospital-Management-System

3.  Compile the project:

    javac Main.java

4.  Run the program:

    java Main
